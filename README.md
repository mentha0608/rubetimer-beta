# Rubetimer

『ドラゴンクエストX』のルベランギス戦向けに作成した、ブラウザでそのまま使える高精度タイマーです。
床の出現タイミングや安全地帯を音声・画面表示で案内し、戦闘中のタイミング管理をサポートします。

**v2.4.0より、ルベランギス Lv2 / Lv3 の切り替えに対応しました。**

---

## ▶ 使い方

1. 画面上部のスイッチから **Lv2 / Lv3** を選択します。
   選択中のLvは背景色と「LEVEL 2 / LEVEL 3」表示でも確認できます。

2. 戦闘開始前に、対象の強さとLEVEL表示が一致していることを確認してください。
   Lvを切り替えるとタイマーは自動でリセットされます。

3. カラミティ開始時は、HP到達後にルベランギスが動きを止め、**腕を回し始めるモーション**を目安にボタンを押します。
   吹き出しが表示されるのを待つのではなく、モーション開始付近で押す想定です。

4. タイマーは床が出現する少し前に時報・案内が鳴るよう調整しています。

5. 押すタイミングが少し遅れた場合は「-0.5」、少し早かった場合は「+0.5」で補正できます。
   「1」「2」などの小ボタンは途中からタイマーを合わせるための補助ボタンです。

6. キーボードまたはキーボードキーを割り当てたコントローラーから操作する場合は、**F8でサークルカラミティ、F9でグランドカラミティ**を開始できます。
   従来の開始キー（サークル：`@` / グランド：`[`）も引き続き使用できます。

7. 設定から事前読み上げ秒数を **7秒 / 10秒** で選択できます。

8. 次案内が不要な場合は、設定から再生をOFFにできます。

9. メトロノーム音は **OFF / 10秒毎 / 5秒毎** から選択できます。

### Lv2について

* サークルカラミティは、床配置が固定ではないためタイミングを中心に案内します。
* グランドカラミティ後の床は **虹 → 虹 → 黄** の順で繰り返します。
* 黄色床では、床のすきま（溝）が固定の安全地帯となるため、画面上に安置を表示します。

## ▶ 主な機能

* 高精度タイマー（`performance.now()` + `requestAnimationFrame()`）
* ルベランギス **Lv2 / Lv3 切り替え**
* 選択中Lvによる背景色・LEVEL表示の切り替え
* Lv切り替え時の自動リセット
* 床出現タイミング基準の進行
* 安全地帯・床パターンの画面表示
* 音声ガイド
* 事前読み上げ（7秒 / 10秒切り替え）
* 次案内のON / OFF設定
* メトロノーム（OFF / 10秒毎 / 5秒毎）
* 音量調整（VOICE / SE）
* ±0.5秒のタイミング補正
* 途中合わせ用ボタン
* 設定のローカル保存

## ▶ 現在の基準値

### Lv2

#### サークルカラミティ

* 初回床まで：約 **6.0秒**
* ループLap：**19.15秒**
* 以降は19.15秒周期で進行

#### グランドカラミティ

* 初回床まで：約 **6.8秒**
* ループLap：**17.75秒**
* 床パターン：**虹 → 虹 → 黄**
* 以降は17.75秒周期で繰り返し

---

### Lv3

#### サークルカラミティ

* 初回床まで：約 **5.7秒**
* ループLap：
  **23.75 / 20.75 / 23.25 / 21.00 / 25.00 / 20.75**

#### グランドカラミティ

* 初回床まで：約 **6.8秒**
* ループLap：
  **22.00 / 24.50 / 22.25 / 24.00 / 22.75 / 23.50 / 23.25 / 23.50 / 23.25 / 23.00 / 23.75 / 22.50**
